# CYCLOPS
The free alternative to Wikipedia
HOW TO USE:
Hello! This SPECIAL article will tell you how to use CYCLOPS.
READING AND DOWNLOADING: The repo can be downloaded as a .zip or be cloned as a .tar easily for reading, The articles will be stored in .docx format. 
WRITING: Write an issue to suggest edits. You can be uploaded to admin status and be a contributor after sometime.
SPECIAL ARTICLES: The License (GPL 3.0) and this README are all SPECIAL articles, mainly because they are .md files and are for specific purposes, not to gain knowledge.
MEDIA: Upload any media to the MEDIA folder.
